## What is SOC?

A **Security Operations Centre (SOC)** is a dedicated team responsible for continuously monitoring an organisation's IT infrastructure for cyber security threats. Their primary goal is to detect, investigate and respond to security incidents before they cause significant damage.

A SOC operates 24 hours a day, 7 days a week in many organisations, analysing data from servers, endpoints, firewalls, cloud platforms, applications and network devices. By centralising security monitoring, the SOC helps organisations reduce the time it takes to identify and respond to attacks.

Rather than waiting for an attack to be reported by users, the SOC works proactively by monitoring logs, investigating suspicious activity and improving security controls over time.

### example

Imagine a shopping centre with dozens of CCTV cameras. Instead of every security guard watching one camera, all of the camera feeds are sent to one security control room. The security team watches for suspicious behaviour, investigates alarms and quickly responds when something unusual happens.

A SOC works in much the same way, except instead of monitoring people, it monitors computers, servers, users and networks.

### Key functions
| Function          | Description                                                             |
| ----------------- | ----------------------------------------------------------------------- |
| Monitoring        | Continuously watching systems for suspicious activity.                  |
| Detection         | Identifying potential cyber threats using alerts and log analysis.      |
| Investigation     | Analysing alerts to determine whether they are genuine threats.         |
| Incident Response | Taking action to contain, remove and recover from attacks.              |
| Reporting         | Documenting incidents and recommending improvements.                    |
| Threat Hunting    | Proactively searching for threats that automated tools may have missed. |

## What is SIEM?

A **Security Information and Event Management (SIEM)** system collects and analyses logs from multiple sources to detect, monitor and investigate security threats.

## SIEM Analogy

A SIEM is like the monitoring equipment in a hospital. Doctors cannot constantly check every patient, so monitors watch vital signs and raise an alarm when something abnormal happens. In the same way, a SIEM continuously monitors systems and alerts analysts when suspicious behaviour is detected.

## Examples of SIEM softwares
- **Splunk Enterprise Security** - SIEM platform used to collect, analyse and investigate security events from multiple data sources in real time 
- **Microsoft Sentinel** - cloud-native siem built on microsoft azure, which helps organisations detect, investigate and respond to cyber security attacks.

## What is Splunk?
**Splunk** is a data platform that collects, indexes, searches and analyses machine-generated data from sources like servers, application, network. It enables organisations to monitor systems, investigate incidents and detect cyber security threat in real time.
